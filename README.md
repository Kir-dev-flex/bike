# ReCycle — E-bike Landing Page

A responsive product landing page focused on bold typography, layered imagery, motion, and interactive product presentation.

## Highlights

- Responsive HTML and modular CSS organized with BEM
- Two Swiper experiences with custom controls
- Scroll-driven wheel and typography animation
- Accessible focus states and reduced-motion support
- Optimized content structure for GitHub Pages
